# IonoScope — фронтенд

Веб-интерфейс для просмотра прогнозов ионосферы, наблюдений станций и проверки
ранее рассчитанных прогнозов по фактическим данным.

## Что реализовано

- Начальный выбор роли, от одной до пяти станций и параметра прогноза.
- Независимое изменение роли, станций и параметра через шапку приложения.
- Работающие станции остаются в списке при задержке прогноза. Статус прогноза
  и время последнего измерения в UTC показаны отдельно; список обновляется
  каждые 30 секунд. Просроченный прогноз не считается действующим.
- Карточки прогнозов с временем расчёта, сроком действия и состоянием данных.
- Графики наблюдений и прогнозов: масштабирование, перемещение, полноэкранный
  просмотр и экспорт PNG. Наблюдения показаны синим, прогнозы — оранжевым.
- Архив расчётов с фильтрами по станции и периоду, сравнением прогноза с фактом,
  абсолютной и процентной ошибкой, метриками MAE и RMSE.
- Таблицы с поиском, сортировкой, выбором строк, страницами и экспортом CSV.
- Локальная история до 30 запросов: переименование, копирование, удаление
  с отменой и очистка с подтверждением.
- Светлая и тёмная темы, настройка размера текста, уведомления внутри приложения.
- Адаптивная боковая панель, содержание результатов и кнопка возврата наверх.
- Обработка загрузки, недоступности данных, устаревших прогнозов и неизвестных
  адресов; повтор запросов после ошибок.
- Подготовленный клиент SSE для объяснений LLM. Объяснения отключены до
  подключения провайдера; интерфейс явно сообщает об этом.

## Технологии

Angular 22, TypeScript, Angular CDK, Tailwind CSS и Plotly.
Standalone-компоненты, OnPush, signals и отложенная загрузка маршрутов.
Точные версии зависимостей зафиксированы в `package.json` и `package-lock.json`.

## Локальный запуск

Требуется Node.js `^22.22.3`, `^24.15.0` или `>=26.0.0`.

```powershell
npm ci
npm start
```

Приложение доступно по адресу http://127.0.0.1:4200.
Без сохранённого выбора открывается мастер настройки, с сохранённым — `/chat`.

## Подключение API

В `src/environments/environment.ts` по умолчанию включён `useMocks: true`:
текущие прогнозы и каталог демонстрационные, что отмечено в интерфейсе.
Архив расчётов всегда использует настоящий API.

Для работы с реальными станциями и текущими прогнозами установите
`useMocks: false` и перезапустите сервер разработки. Запросы `/api` проксируются
на `http://127.0.0.1:8000`; адрес задаётся в `proxy.conf.json`.

Production-конфигурация отключает моки. `explanationsEnabled: false` в обеих
конфигурациях: до настройки LLM-провайдера объяснения не запрашиваются.

Для проверки состояний демонстрационного прогноза доступны адреса
`/chat?mock=stale`, `/chat?mock=expired` и `/chat?mock=error`.

## Проверки и сборка

```powershell
npm run typecheck
npm run lint
npm run format:check
npm test
npm run build
```

Тесты покрывают обработку API, историю запросов, CSV, SSE, ограничение
параллельных запросов, календарь, сортировку и сопоставление исторических данных.

Production-файлы создаются в `dist/`, точка входа — `dist/index.html`.
Для SPA-маршрутов веб-сервер должен возвращать `index.html`.
Инфраструктура использует каталог через `IONOSCOPE_FRONTEND_DIST`.

`node_modules`, сборки, кэш, локальные `.env`, логи и результаты проверок
исключены из Git через `.gitignore`.
